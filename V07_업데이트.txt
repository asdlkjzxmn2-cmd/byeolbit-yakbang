V07 변경 내역과 밸런스

오류 수정
• V06에서 제조 시 시간만 흐르고 재고가 늘지 않던 문제를 재현하고 수정.
  스크롤 복원 중 잘못된 CSS 선택자가 생성되어 제조 결과 처리 직전에 멈추는 오류였음.
  이제 유효한 선택자를 쓰고 행동 결과까지 처리한 뒤 화면을 갱신함.
  이미 오류로 지나간 시간을 소급 복원하지는 않으며, V07에서의 제조는 정상 처리됨.
• 아이폰 가로 진열대 4번 이후 잘림: 팝업 높이를 실제 화면 높이 안에 고정하고
  내용 영역이 독립적으로 스크롤되도록 수정. 아이패드에도 같은 규칙 적용.
• 아이폰/아이패드 세로 레이아웃 추가. 세로 실내 풍경은 바깥 빈 배경만 줄여 확대하고
  하단에는 오늘 매출·판매·의뢰·조합법 수를 배치. 가로 회전 시 자동 재배치.
• 품목 선택·수량 변경 후 스크롤 유지. 모바일 선택 상자의 글자 크기 보완.

창가와 유행 정보
• 계절별 창가 꽃: 봄 분홍, 여름 노랑, 가을 주황, 겨울 흰색.
• 모카의 기존 계절·운영 대화에 낮은 비중의 창가 꽃 대사 추가.
• 오늘 유행 제품은 아침 운영일지에 기록하지 않음. 기존 해당 기록도 저장 이전 때 제거.
• 모카가 오늘 유행 제품명을 직접 알려주는 대사도 제외. 광장 게시판에서 확인.

1. 계절 행사
달력: 한 계절 12일, 1년 48일. 각 계절 10~12일에 3일 동안 행사.
시작 5일 전부터 광장 게시판에 준비 품목과 특별 의뢰 표시.
봄빛 꽃시장 / 별비 축제 / 가을 수확장 / 겨울 등불제.
요구 품목은 해마다 다른 조합으로 순환. 행사마다 특별 의뢰 1건 선택 가능.
특별 의뢰 수량 = 6 + 제품 숙련 레벨×2, 단가 = 기본 판매가의 약 155%.
행사 상품은 행사 기간 판매가 20% 상승, 선택 확률 증가. 방문객도 추가.
수락·거절은 경험치 변화 없음. 성공/기한 초과의 평판 규칙은 기존 의뢰와 동일.

2. 새 채집 구역
별무리 습지: 이슬초원의 오래된 다리 복구.
필요: 숙련 Lv.2, 900G, 유리광석 30, 은잎풀 25, 작업 2시간.
전용 재료: 별이슬 갈대 / 물별꽃.
발견 제품: 물별꽃 차(Lv.2), 잔물결 잉크(Lv.3).

유리온실: 달그늘 숲의 버려진 온실 복구.
필요: 숙련 Lv.4, 2400G, 유리광석 65, 반딧불 가루 15, 작업 2시간.
전용 재료: 온실 햇씨 / 호박빛 잎.
발견 제품: 햇씨 꿀방울(Lv.4), 호박빛 온실향(Lv.5).

구역마다 1시간 채집 시 주요 전용 재료 최소 6개, 보조 전용 재료 최소 3개.
무작위 수확으로 추가 획득. 전용 재료는 시장에서 판매하지 않음.
첫 제조법은 해당 구역 채집 2회부터, 두 번째는 5회부터 숙련 조건 충족 시 영감 이벤트로 습득.
해금된 구역은 지도에도 표시. 제조법은 도서관에서 구입할 수 없음.

숨겨진 구역 제품 의뢰
일반 의뢰 발생 시 0.6%의 낮은 확률로 별도 판정. 8일째부터 등장 가능.
전체 숨겨진 구역을 합쳐 1년에 최대 1회이며, 직전 등장 후 최소 48일 간격.
새 구역 해금 후에도 일반 의뢰 후보에는 섞지 않아 이 제한을 유지.
숙련이 현재보다 최대 1단계 높은 제품까지. 소량 3~5개, 기본 준비 기간 18일 + 학습 여유.
의뢰인이 구역 접근 경로를 설명. 시장의 로웬 → 길의 소문에서 다시 힌트 확인 가능.

3. 제품 연구
가게 레시피북 → 제품 연구 수첩에서 확인.
실제 완성 수량과 유상 판매·납품 수량, 숙련 조건을 모두 채우면 자동 습득.
연구 제품은 일반 진열대에서 최초 1개가 팔린 이후에만 의뢰·유행 후보에 포함.
농축 달빛 차: 달빛 차 제작 24 / 판매 12 / 숙련2.
달빛 시럽: 달빛 차 제작 60 / 판매 30 / 숙련3.
산들 농축활력약: 산들 활력약 제작30 / 판매15 / 숙련2.
밤샘 반딧불 램프: 반딧불 등불 제작30 / 판매15 / 숙련3.
깊은잠 향주머니: 포근한 꿈향 제작30 / 판매15 / 숙련4.
구름결 섬유향: 구름 향수 제작30 / 판매15 / 숙련4.
겹유리 수호부적: 유리빛 부적 제작35 / 판매18 / 숙련5.
자정의 정제영약: 한밤의 영약 제작40 / 판매20 / 숙련6.
기존 28개 + 탐험 4개 + 연구 8개 = 총 40개 제품.

4. 할인·추천 진열대 입소문
평판 Lv.2 이상에서 가능. 판매와 진열 두 조건을 모두 채워야 함.
할인대는 판매 1개당 입소문1, 재고 있는 영업1시간당 진열 입소문1시간.
추천대는 각각 60%씩 쌓임. 같은 제품의 기록은 위치를 바꿔도 합산·보존.
평판2: 판매 입소문40 + 진열63시간 (할인대 기준 영업7일).
평판3: 판매30 + 진열45시간 (5일).
평판4: 판매22 + 진열27시간 (3일).
평판5: 판매15 + 진열18시간 (2일).
평판6: 판매10 + 진열9시간 (1일).
품절·폐점 시간은 집계하지 않으며 납품도 입소문 판매량에 넣지 않음.
조건 충족 시 다음날부터 3일간 유행. 약방에서 만든 유행은 한 번에 한 품목.
같은 제품은 발현일로부터 7일간 재발현 대기. 준비 기간의 조건은 계속 누적.
이미 유행 중인 제품을 할인·추천 진열대에 놓으면 방문객 증가,
해당 제품을 고르는 비중 상승, 구매 확률 78% → 94%.
선택 확률의 추가 효과는 할인대가 추천대보다 큼. 할인대의 10% 할인은 유지.

검증
• 실제 Chromium 브라우저에서 기존 제조 오류 재현 → V07 수정 후 연속 5회 제조 재고 확인.
• 7개 화면 크기/모드, 10종 팝업의 화면 내 배치 검토.
  iPhone 390×844, 844×390, 375×667, 667×375;
  iPad 768×1024, 1024×768; PC 1280×800.
• 진열 12번까지 브라우저 스크롤·상품 선택, 회전 중 상태 유지, 레시피 선택 스크롤 검사.
• 전체 40개 제품 제조, 탐험 복구비용/수확/영감, 연구 조건, 희귀 의뢰 연간 제한 검사.
• 행사 기간/중복 수락·보상 방지, 평판별 입소문 및 추천대 60% 집계 검사.
• 100일 플레이와 저장 재불러오기 시뮬레이션.
• 기존 BGM 데이터 그대로 유지. 실제 iPhone/iPad의 Safari 엔진 및 기기 터치·오디오 테스트는 별도 필요.
