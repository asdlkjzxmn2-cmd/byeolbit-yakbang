업로드
1. ZIP 파일의 압축을 풉니다.
2. 안에 있는 index.html을 기존 GitHub 저장소의 index.html 대신 업로드합니다.
3. 기존 GitHub Pages 주소에서 새로고침합니다. 세 기기 모두 같은 주소를 씁니다.
새 저장소나 기기별 폴더는 필요 없습니다. ZIP 파일 자체를 올리지 마세요.
.nojekyll, README_KO.txt, V07_업데이트.txt는 함께 올려도 됩니다.

저장 이전
업로드 전 기존 게임 → 저장 수첩 → 저장 파일 내보내기로 JSON을 보관하세요.
같은 주소·같은 브라우저에서는 기존 자동 저장을 이어서 읽습니다.
진행이 보이지 않으면 V07의 저장 수첩에서 JSON을 불러오세요.
V06까지의 돈·재고·숙련·평판·진열대·의뢰·배운 조합법을 유지합니다.
과거의 '오늘 유행 상품은…' 운영일지만 삭제하고, 연구 및 탐험 기록을 새로 추가합니다.
과거 제작 누적 수량은 저장되어 있지 않아 V07부터 집계합니다.
이전 저장에 남아 있는 최근 판매 기록은 연구 판매 수량에 반영합니다.
V07 저장 파일은 이전 버전에서 읽을 수 없으니 이전 저장 사본을 보관하세요.
기기 간 자동 저장 동기화는 없습니다. 내보내기/불러오기로 이동하세요.

화면
첫 화면에서 실행 환경을 선택합니다. 게임 중 화면 설정에서도 변경할 수 있습니다.
아이폰·아이패드 모드 모두 세로/가로 회전에 자동 대응합니다.
세로: 풍경과 대화, 오늘의 운영 정보를 위아래로 배치합니다.
가로: 풍경 왼쪽, 메뉴·대화 오른쪽. 조합/시장 팝업은 목록·상세가 좌우로 나뉩니다.
상품 진열은 팝업 내부를 위아래로 스크롤하면 12번까지 접근할 수 있습니다.
아이폰에서는 Safari로 배포 주소를 여세요. 파일 앱 미리보기는 사용하지 마세요.
브라우저의 회전 잠금을 해제해야 화면 방향이 바뀝니다.
