별빛 약방 V06 통합판 · 아이폰 / 아이패드 / PC

한 저장소, 한 주소로 세 기기 모두 실행합니다.
첫 화면에서 실행 환경을 고른 뒤 새 이야기 또는 이어하기를 누르세요.
기기에 맞는 환경을 처음에 제안하고, 이후에는 마지막 선택을 기억합니다.
게임 중에도 화면 설정 메뉴에서 변경할 수 있습니다.
화면 환경만 바뀌며 돈·재고·시간·레벨·저장 데이터·BGM은 유지됩니다.
아이폰 모드는 회전 잠금을 풀고 가로로 사용하세요.

GitHub에 한 번 업로드
1. 이 ZIP을 압축 해제하세요.
2. index.html을 기존 저장소의 index.html 대신 업로드하세요.
   README_KO.txt와 .nojekyll도 함께 올릴 수 있습니다.
3. 기존 GitHub Pages 주소를 그대로 사용합니다.
새 저장소나 기기별 폴더를 만들 필요가 없습니다.
별빛_약방_V06_통합.html 단독 파일을 받았다면 index.html로 이름을 바꿔 올려도 됩니다.
ZIP 자체를 업로드하는 것이 아니라 압축을 푼 index.html을 올려야 합니다.

저장과 이전
업로드 전 기존 게임의 저장 수첩에서 JSON 저장 파일을 내보내 두세요.
같은 주소·같은 브라우저의 기존 자동 저장은 그대로 이어집니다.
기기 사이의 자동 동기화 기능은 없습니다.
PC → 아이폰 등 기기를 바꿔서 이어 할 때는 저장 파일 내보내기/불러오기를 사용하세요.
V06 이전 저장 파일도 불러올 수 있습니다.

실행 환경
아이폰: 풍경 왼쪽, 메뉴·대화 오른쪽. 조합·시장 팝업도 좌우 배치.
아이패드: 큰 터치 버튼, 태블릿 화면 배치.
PC: 넓은 화면용 기존 배치.
iOS 파일 앱 미리보기 대신 배포된 페이지를 Safari에서 여세요.
음악은 새 이야기/이어하기를 누르면 시작하며 효과음과 별도로 켜고 끌 수 있습니다.

검토
환경 전환 시 상태 유지, 환경 선택 저장, 모든 팝업 생성, 기존 게임 로직 검사를 수행했습니다.
실제 iPhone/iPad Safari 기기 테스트는 수행하지 못했습니다.
이번 통합판에는 새로운 콘텐츠나 밸런스 변경을 추가하지 않았습니다.
