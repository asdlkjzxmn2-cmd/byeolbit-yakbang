별빛 약방 V06 · 실행 및 GitHub 업로드 안내

PC
별빛_약방_V06_PC.html을 Chrome 또는 Edge에서 열어 주세요.
인터넷 연결 없이 실행할 수 있으며 BGM도 파일에 포함되어 있습니다.
새 이야기 / 이어하기를 누르면 BGM이 시작됩니다.

 iPad
별빛_약방_V06_iPad.html은 터치 버튼 크기를 확대한 버전입니다.
iPad 파일 앱의 HTML 미리보기에서는 게임 실행이 제한될 수 있습니다.
아래 GitHub Pages 주소를 Safari에서 여는 방식을 권장합니다.
Safari의 공유 → 홈 화면에 추가로 바로가기를 만들 수 있습니다.
홈 화면 바로가기는 오프라인 설치를 보장하지 않습니다.
기기를 잠그거나 앱을 백그라운드로 보내면 iPad가 소리를 중단할 수 있습니다.
실제 iPad 기기에서의 동작 검증은 수행하지 않았습니다.

GitHub Pages
1. 이 ZIP 파일을 압축 해제합니다.
2. GitHub 저장소를 만들고 index.html, .nojekyll, README_KO.txt를 루트에 올립니다.
   ZIP 자체를 업로드하는 방식이 아닙니다.
3. 저장소 Settings → Pages에서 Deploy from a branch를 선택합니다.
4. main 브랜치 / (root)를 선택하고 Save를 누릅니다.
5. 표시되는 배포 주소를 PC 브라우저 또는 iPad Safari에서 엽니다.
index.html은 PC와 터치 기기에 자동 대응합니다. 별도 빌드는 필요 없습니다.

저장 파일 이전
기존 게임 → 저장 수첩 → 저장 파일 내보내기로 JSON을 보관하세요.
V06 → 새 이야기 → 저장 수첩 → 저장 파일 불러오기로 이어 할 수 있습니다.
기기, 파일 위치, 사이트 주소가 달라지면 자동 저장은 공유되지 않습니다.
V06은 이전 저장 파일의 레벨과 경험치 진행률을 유지하며 변환합니다.
V06 저장 파일은 이전 버전에서 사용하지 마세요.

V06 변경 사항
• 팝업 목록 선택 및 수량 변경 시 스크롤 위치 유지.
• 진열대 초기 6개, 최대 12개. 추가 비용: 250 / 400 / 600 / 850 / 1150 / 1500 G.
• 검은 머리, 브라운·금색·흰색 트위드 베레모, 녹색 스카프.
• 조합 목록: 레시피명 / 숙련 / 판매가 / 보유 정렬, 첫 클릭 내림차순.
• 기록: 습득만 → 미습득만 → 모두 표시 반복.
• 도서관 서가: 레시피명 / 숙련 / 판매가만 표시하고 정렬 가능.
• 조합법 상세의 인기 계절 표시 제거. 중앙광장 게시판에서 확인.
• 숙련과 평판의 레벨업 필요 경험치 2배. 초록색 게이지로 현재 레벨 진행률 표시.
• 의뢰 생성 시 약 15% 확률로 현재 또는 다음 숙련 레벨의 미습득 제품 요청.
  미습득 의뢰에는 학습 준비 기간을 추가합니다.
• 의뢰 수락·거절·미수락 제안 만료는 경험치 변화 없음.
• 납품 성공: 평판 경험치 12 + 수량×2. 수락 후 기한 초과: 8 + 수량 감소.
  평판 경험치는 0 아래로 내려가지 않으며 레벨이 내려갈 수 있습니다.
• 기존 28개 제품, 자동 판매, 모카 대화, 손님 애니메이션, BGM 반복 유지.

검토
자동 DOM/게임 로직 검사: 정렬·필터·스크롤·진열대·저장 변환·경험치·의뢰.
회귀 검사: 모든 레시피 제조, 판매 애니메이션, 모카 대화, BGM 원본 및 반복 설정.
캔버스 캐릭터와 12개 진열대 그림 검토 완료.
실제 PC 브라우저 및 iPad Safari의 화면·오디오 재생 검증은 별도 필요합니다.
